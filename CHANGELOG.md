# Changelog

## 0.1.4 — public preview candidate

- Fix overlapping icons and Chinese labels in the mute and pin buttons.
- Add public repository documentation, pinned dependency preparation, and release packaging.

## 0.1.3

- Use owned CPU bitmaps and ordinary Core Graphics/AppKit drawing to address black window capture in Zoom web sharing.
- Keep frame delivery bounded while scrolling or rotating the iPad.
- Add renderer checks for color conversion, source ownership, orientation, and continuous motion.

## 0.1.2

- Correct UxPlay's legacy SRP-SHA1 proof length validation for first-time PIN pairing.
- Validate pairing payload lengths and states; report pairing progress in the app.
- Check initial pairing, trusted reconnection, and incorrect PIN rejection with a simulated client.

## 0.1.1

- Improve AirPlay pairing and connection diagnostics.

## 0.1.0

- Initial native macOS app with AirPlay and USB mirroring into a resizable window.
